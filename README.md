# simjar-excel-v1
SIMJAR (Sistem Informasi Manajemen Jadwal Pembelajaran) adalah aplikasi berbasis Microsoft Excel yang dirancang untuk membantu pengelolaan jadwal pembelajaran secara otomatis. SIMJAR mendukung manajemen data guru, mata pelajaran, kelas, distribusi mengajar, validasi konflik, serta menghasilkan berbagai laporan jadwal dan pembagian tugas mengajar.
